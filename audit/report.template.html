How to plug in your own keys

All 26 projects read from one file. Edit C:\Users\weezy\agencyos-audit\_infra\secrets.env:

NVIDIA_API_KEY=nvapi-...your key...
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net
NIM_MODEL=openai/gpt-oss-20b

Then render it into every project and restart:

powershell -File _infra\apply-runtime-fixes.ps1
powershell -File _infra\apply-secrets.ps1
powershell -File _infra\stop-all.ps1
powershell -File _infra\start-all.ps1
powershell -File _infra\health.ps1

apply-secrets.ps1 expands {{NVIDIA_API_KEY}}, {{NIM_MODEL}} and {{MONGO:dbName}} inside each project's .env.audit-template. Leave MONGODB_URI blank to keep using the local Mongo.
